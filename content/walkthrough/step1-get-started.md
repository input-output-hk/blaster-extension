## Getting Started

Thanks for installing the High Assurance SC extension!

To get started navigate to the extension [settings](command:workbench.action.openSettings?%5B%22blaster%22%5D) to begin initializing the extension.
If you need any some additional guidance to learn how to use this extension you can refer to the [documentation](https://placeholder.docs) tab or the [examples](https://placeholder.examples).

Make sure to check the dependencies tab to install all the extensions required to use all the capabilities accessible the Blaster SC extension.
